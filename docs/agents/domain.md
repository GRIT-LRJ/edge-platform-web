# Domain Docs

Before exploring the repository, read:

- `CONTEXT.md` at the repository root.
- Relevant ADRs under `docs/adr/`.

Missing domain documents should not block work. Create or update them only when domain terminology or architectural decisions need to be recorded.

## Layout

This repository uses a single-context layout:

```text
/
|-- CONTEXT.md
|-- docs/adr/
`-- src/
```

Use terminology defined by the domain glossary. Explicitly flag proposals that conflict with an existing ADR.
